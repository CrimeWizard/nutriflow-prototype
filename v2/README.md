# NutriFlow Prototype v2

**Egypt-first, commerce-first** — separate from [v1](../nutriflow-prototype).

## What's different from v1

| v1 | v2 |
|----|-----|
| Macro rings & daily tracking | **No logging** — buy, don't track |
| Generic products | **Egyptian brands** (Almarai, Juhayna, Americana…) |
| Recipe → flat ingredient list | **Get ingredients** — pick brand & size per ingredient |
| EGP / COD not emphasized | **EGP prices**, cash on delivery |
| 6 tabs + AI coach | **4 tabs** — Home, Recipes, Shop, Cart |

## Core flows

1. **Home** — Today's meals, one tap "Add today's plan to cart" (smart defaults)
2. **Recipes** → **Get ingredients** — choose Almarai vs Juhayna yogurt, ¼ kg vs ½ kg chicken, etc.
3. **Cart** — Checkout with COD (demo)

## Run

```bash
npm install
npm run dev
```
