# NutriFlow Prototype v4

**Dual marketplace** — healthy restaurants + supermarket groceries, unified cart, profile page, full checkout.

Egypt-first, commerce-first, English UI. No daily tracking.

## What's new in v4

| v3 | v4 |
|----|-----|
| Groceries only | **Restaurants** (browse → menu → add meals) + **Groceries** |
| No profile screen | **Profile page** — edit details, gym days, goal, recent orders |
| Single-vendor cart | **Grouped cart** — "From Green Bite" vs "From Carrefour" |
| 4 tabs | **5 tabs**: Home · Eat out · Groceries · Cart · Profile |

## User flow

1. Onboarding (welcome → gym → goal → delivery)
2. **Home** — mixed meals (restaurant + cook-at-home)
3. **Eat out** — browse restaurants → menu → add to cart
4. **Groceries** — recipes + products → shop ingredients
5. **Cart** — grouped by vendor → checkout → pay on delivery
6. **Profile** — edit name, phone, area, training, goal

## Run

```bash
npm install
npm run dev
```

Default port: **5176**
