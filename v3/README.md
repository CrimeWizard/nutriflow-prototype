# NutriFlow Prototype v3

**Full journey prototype** — onboarding → personalized home → shop ingredients → checkout → order success.

Egypt-first, commerce-first, English UI. No daily tracking.

## What's new in v3

| v2 | v3 |
|----|-----|
| Jump straight into app | **4-step onboarding** (welcome → gym days → goal → delivery) |
| No checkout | **Full checkout** with COD |
| No order confirmation | **Order success** screen with order ID + ETA |
| Single App.tsx | **Screen components** + shared context |
| — | **Persists profile** in localStorage |
| — | Settings icon resets demo onboarding |

## User flow

1. **Welcome** → Get started
2. **Gym days + time** → Continue
3. **Goal** (lose / stay fit / build muscle) → Continue
4. **Name, phone, area** → See my meals
5. **Home** — personalized hero + today's meals
6. **Shop ingredients** — pick Almarai vs Juhayna, etc.
7. **Cart** → Continue to checkout
8. **Checkout** → Place order (pay on delivery)
9. **Success** → Back to home

## Run

```bash
npm install
npm run dev
```
