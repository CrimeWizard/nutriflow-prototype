# NutriFlow Prototype

Interactive mobile-first prototype for a healthy food & fitness marketplace app.

## Features demonstrated

- **Home** — Daily macro tracking, gym-aware meal timeline, quick add
- **Shop** — Supermarket, restaurants, supplements, gym gear, utilities
- **Recipes** — Pick a recipe → auto-build supermarket cart with macros
- **Plan** — Weekly diet plan with budget tracking, one-tap purchase
- **AI Coach** — Chatbot with quick prompts for meal advice
- **Profile** — Weight/body stats, InBody upload, kitchen inventory, gym schedule

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173
